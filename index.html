Architecture of this website

A static front end with a serverless back end on two clouds.

Swipe sideways to see the full diagram →

  1. Load: GitHub Pages serves the site as static files: nothing to patch, HTTPS by default.
  2. Send: the contact form posts to Azure Functions, which stores the message, then emails it.
  3. Failover: if Azure times out or returns a server error, the same request goes to AWS Lambda.
  4. Last resort: if both clouds are down, the visitor's email app opens with the message filled in.

Swipe sideways to see the full diagram →

Cost guardrails: a $2/month budget alert on AWS and on both Azure subscriptions. Every service runs on a scale-to-zero serverless plan, so idle cost is about $0.
